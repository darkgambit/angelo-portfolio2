# Angelo De Ocampo — Portfolio Website

A responsive, accessible, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser. For the best local experience, use a tiny static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy free
- **GitHub Pages:** push these files to a repository, then enable Pages under **Settings → Pages**.
- **Netlify:** drag the unzipped folder into Netlify Drop.
- **Vercel:** import the repository as a static site.

## Customize
- Portfolio copy and links: `index.html`
- Colors and layout: the variables at the top of `styles.css`
- Case-study modal content: the `cases` object in `script.js`
- Portrait: `assets/angelo-profile.webp`

## Important before publishing

## Impact estimate assumptions
The displayed savings are illustrative portfolio estimates, not audited client outcomes. They assume moderate recurring use and value manual time at USD $10 per hour. Software subscriptions, API charges, human review, and exceptions are excluded. Replace the estimates with measured production figures whenever available.
